## 它和普通榜单有什么不同

大多数榜单按标价排序。器度按**买新琴、用三年、再卖掉，实际亏了多少钱**排序。

核心口径：

- **净亏损 V**：买新琴三年后卖出的实际亏损额（不是标价差）
- **四维评分**：音色 / 手感 / 用料 / 可靠性
- **3×3 偏好档位**：更看重音色还是手感 × 更看重价格还是评分，切换后全场重排

因为口径不同，便宜不等于划算，贵也不等于不值——这正是榜单想说明的事。

## 本地运行

无需安装、无需构建、无后端：

1. 下载本仓库
2. 双击 `docs/index.html`

页面通过 `data.js` / `tiers.js` 本地加载数据，不依赖任何网络请求。

## 方法论

`collect-method/` 目录下按流水线顺序存放各阶段方法与判读规则文档：

- 价格获取与去重口径
- 二手价折算与净亏损计算
- 音色 / 用料 / 手感的判读标准（含评分手册与一致性检验）
- 合榜、计算与导出
- 发布前校验闸门

> 该目录**仅提供方法论说明**，不含可执行采集脚本。原因见 `collect-method/README.md`。
