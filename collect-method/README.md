# 采集与评分方法论

本目录说明「器度」榜单的数据是怎么来的、怎么算的。**只包含方法说明，不包含可执行的采集代码。**

## 为什么只有文档

采集行为涉及各平台的服务条款与访问政策。为避免公开可直接运行的采集实现，本仓库仅保留方法论层面的说明：

- 每一阶段的**目标、输入、输出、判定标准**
- **口径规则**：什么算有效样本、怎么去重、怎么处理缺失、什么时候不许估算
- **校验规则**：发布前必须通过哪些检查

具体实现与运行环境不在本仓库范围内。文档中若出现命令行示例，均为历史记录，其中的路径与脚本不在本仓库中。

## 关键口径

1. **价格以净亏损为准**：不看标价差，看「买新、用三年、卖掉」的实际亏损。
2. **缺失一律标注，不做假精度**：没有数据就显示「—」，不估算填充。
3. **插补必须标明**：用同品牌或全榜均值填补的值，必须标「插补」，不得冒充实测。
4. **判读需一致性检验**：多人/多次判读结果需达到约定一致性阈值才可采用。
5. **描述性指标不排名**：如手感四轴只做画像描述，不合成总分、不排名。
