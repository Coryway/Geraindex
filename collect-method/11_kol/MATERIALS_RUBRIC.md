# 用料判读规范（MATERIALS_RUBRIC）· 8 档 + 16 锚点

> 版本：v1.0（2026-11-16）｜ 适用：新增款用料分判读
> 相关：`_过目/268`（为什么用料与价格强相关）、`_过目/260`（为什么不做纯公式）

---

## 0 一句话原则

**用料分判的是「制造成本档次」，不是「好不好听」。**

- 判"这套材料与工艺值多少钱"，不是"这琴声音怎样"
- 产地、贴面、漆面、五金**都算**，因为它们都是成本项
- 不看品牌，不看售价，不看市场口碑

> 为什么不用公式：纯配置公式能读"骨架"（木头、五金），读不到"精装修"（硝基漆、实木贴面、做工），
> 实测换上会让 90 款动、最大 21 名、Top10 换 3 席（`_过目/267`、`/268`）。
> 最终裁决：**维持 AI 判读，公式只作配置表展示**。

## 1 八档刻度

| 档 | 代表分 | 区间 | 一句话 |
|---|---|---:|---|
| M1 | **55** | ≤56 | 入门代工：便宜木 + 通用五金 |
| M2 | **59** | 57–60 | 入门偏上：好一点的木，五金仍通用 |
| M3 | **63** | 61–64 | 中端：结构或用料有一项到位 |
| M4 | **67** | 65–68 | 中端偏上：木材与结构都合格，缺精修 |
| M5 | **71** | 69–72 | 专业级入门：主力品牌量产线 |
| M6 | **75** | 73–76 | 专业级：高品控产地 + 好木 |
| M7 | **78** | 77–79 | 准定制：实木贴面 / 手工工序 |
| M8 | **81** | ≥80 | 定制级：顶级木 + 顶级五金 + 顶产地 |

> 判读输出 = 档位 + 代表分，不做档内微调（与音色同规则）。

## 2 六个判据（看这六项，不看总分加权）

| # | 判据 | 观察点 | 上/下沿示例 |
|---|---|---|---|
| 1 | **琴体结构** | 实心 / 半空心 / 层压 / 空心；有无独立贴面 | 层压=下沿；实心+实木贴面=上沿 |
| 2 | **木材族** | 椴木/杨木/南洋木 → 桃花心/桤木/梣木 → 枫木顶+桃花心背 → 实木花纹枫 | 杨木=下沿；实木火焰枫=上沿 |
| 3 | **琴颈与指板** | 枫木+玫瑰木 / 桃花心+玫瑰木 / 枫木+枫木 / 乌木；有无包边、多层结构 | 月桂/贾托巴=下沿；乌木+包边=上沿 |
| 4 | **五金电器** | 琴桥、弦钮、是否锁定、是否品牌件（Gotoh/Schaller/Hipshot/Floyd） | 通用压铸=下沿；品牌件+锁定=上沿 |
| 5 | **漆面工艺** | 聚酯 / 聚氨酯 / 硝基 / 哑光手工；**官方未公布时记 null，不当低分** | 聚酯=下沿；硝基=上沿 |
| 6 | **产地与品控** | 中国代工 / 印尼 / 墨西哥 / 日本 / 美国 / 手工产线 | 代工=下沿；美日或手工=上沿 |

**重要**：这六项不是加权求和，是**定位**——先按「结构与木材」定大致档次，再看五金/漆面/产地做**上下一档**的调整。

## 3 十六个锚点（每档 2 把）

### M1 · 55
- `Squier Affinity`（53）：杨木 + 通用五金 + 聚酯漆 + 代工
- `Fender Standard Strat`（55）：杨木（不是桤木）+ 通用五金；**同价位但用杨木，所以没进 M2**

### M2 · 59
- `Ibanez RG350`（58）：Meranti（南洋木，替代桃花心）+ HSH
- `Epiphone Les Paul Special DC`（60）：桃花心 + set-in，木到位但五金通用

### M3 · 63
- `Casino`（61）：层压枫木 + P90；结构是层压（下沿），但全空心工艺有成本
- `Tagima Stella`（61）：非桃 + 水波纹枫贴面；贴面是装饰级（薄），不算实木

### M4 · 67
- `RSE20`（66）：腔体桃花心 + 聚氨酯漆 + 印尼产
- `Gretsch G2622T`（66）：层压枫木 + center block + 印尼产；半空心工艺拉回中档

### M5 · 71
- `American Performer Strat`（70）：桤木 + 美产 Corona + 聚氨酯漆（**不是硝基**，所以没到 M6）
- `PRS SE Custom 24`（70）：桃花心 + 枫木**贴面**（不是实木）+ 印尼产

### M6 · 75
- `Gibson Les Paul Studio`（73）：桃花心 + 枫木顶 + 美产，但减配（无包边、无硝基）
- `MIJ Hybrid II Strat`（74）：桤木 + 日产 FujiGen + 聚酯漆；品控是加分项

### M7 · 78
- `Eastman SB59`（78）：整块奥古曼 + **实木**火焰枫顶 + 中国手工产线
- `Revstar RSP02T`（78）：枫木顶 + 腔体桃花心 + 日产 + 品牌五金

### M8 · 81
- `Ibanez AZ2204`（80）：日产 + 不锈钢品丝 + Gotoh 五金 + 烤枫木颈
- `Ibanez AZ2402`（81）：同上 + 更高级贴面与电路；**当前全榜用料最高分**

> M7/M8 样本少（4 款 / 2 款），锚点只作标定，不作统计推断。

## 4 判读流程

1. **定位**：按琴体结构 + 木材族，先粗定 M1–M5 中的一档
2. **上/下调整**：
   - 五金为品牌件 / 锁定弦钮 → +1 档
   - 漆面为硝基 / 实木贴面 / 手工产线 → +1 档
   - 层压结构 / 杨木椴木 / 无独立贴面却标高价款 → −1 档
3. **封顶规则**：结构是层压的，最高 M4（除全空心手工琴）
4. **写三条理由**：必须指向六判据中的具体项

### 边界规则
- 漆面未公布：**记 null，不扣分**（PRS / Ibanez 官方 spec 无此栏，16 款永远抓不到）
- 贴面「已确认无」与「未采集」要分开（见 `_过目/272` §五）
- 第三方拾音器不算用料分（那是音色维度的事），但算五金电器

## 5 一致性验收

与音色同一套工具与门槛：

| 指标 | 门槛 |
|---|---|
| 锚点平均偏差 | ≤ 2.0 分 |
| 锚点 QWK | ≥ 0.90 |
| 理由完整率 | 100% |

**本轮未做 15 款盲测**，原因：漆面 23/95、贴面 19/95、重量 0/95，
现在测出来的差异主要是"信息缺口"，不是"判读漂移"，测了会误导。
建议在琴行补完厚度/重量/漆面后再做首测（同音色方法）。
